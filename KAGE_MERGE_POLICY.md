# KAGE Merge Policy

The Kage build is preservation-first and additive.

- Existing Nori V36.5 remains the base.
- The supplied full Jarvis source is preserved in protected source parts.
- Jarvis is exposed from Nori navigation as JARVIS TOOLS instead of replacing the Nori/KAGE workspace.
- Jarvis AI requests are routed to the authenticated Nori Brain provider layer.
- Jarvis local memory/progress is persisted locally when cloud storage is unavailable.
- Existing deterministic KAGE state remains authoritative; AI may explain and recommend but must not invent protected state.
- Human Override remains above discipline optimization.
- Genuine constraints are considered before discipline escalation; repeated unsupported avoidance can be addressed directly.
- The three specified administrator emails are retained as exceptional administrator identities.
- No existing Nori module is intentionally deleted by this merge.
